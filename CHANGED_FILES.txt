DEPLOY
1. git add . && git commit -m "Share links" && git push     (Actions rebuilds + reloads)
2. ONE manual VPS step (only needed for the WhatsApp/Telegram preview card;
   links work without it):
     sudo nano /etc/nginx/sites-available/matinee.prahladsingh.in
   Inside the main server block (the one with "listen 443 ssl"), add this ABOVE "location /assets/":

     location /s/ {
         proxy_pass http://localhost:5009;
         proxy_set_header Host $host;
         proxy_set_header X-Real-IP $remote_addr;
         proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
         proxy_set_header X-Forwarded-Proto $scheme;
     }

   then:  sudo nginx -t && sudo systemctl reload nginx
No .env changes needed.
